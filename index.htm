 		 Longhorn, Complete.

This mod is based on Windows XP and tries to replicate the infamous Windows Longhorn without all it's bugs, nonsense and tries to keep stability and usability at a fair baseline.

It is based on the latest April 2019 updates for Windows XP, some features you can expect and use in this mod are:

  • WinFS
  • Plex, Slate and Jade themes (Jade is included in Home Advanced and higher, Slate is included in place of Plex in Professional and Enterprise, however it is included in Ultimate Edition)
  • Aero transparency using Borderskin and Transbar (no DWM Effects or Compositioning, though)
  • .NET Framework 1.1 to 3.5 and Visual C++ 2005
  • Windows Longhorn wallpapers, both Pre and Post reset, along with ones used in presentations
  • Windows Media Player 10
  • x86 and x64 support (IA-64 support is planned, but remains unconfirmed)
  • Tablet PC features in Home Advanced, Professional, Enterprise and Ultimate
  • Media Center in Home Advanced and Ultimate (Optional in Professional, however not enabled by default)
  • Extra themes, Wallpapers, Tools and Games via the Extras and Ultimate Extras Packs
  • Extra Itanium features in the Itanium+ SKU (an IA-64 Ultimate install can be converted to Itanium+)
