 		 Windows Glass Deployment Kit

The Windows Glass Deployment Kit is a set of tools for Windows Glass built to help deploy it across fleets of computers in a network. It includes the core tools such as ximage and the Windows Glass PE

You can use these tools to create a custom Windows Glass Image with your drivers, programs, branding and settings, these tools can also be used on Windows XP and Idaho, however it is not recommended without installing One-Core-API and it's Modern Setup component first, as that allows Windows XP to be deployed from WIM properly.

Downloads are not available yet, however they will be when the Deployment Kit is ready.
